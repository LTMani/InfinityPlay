# Snakes & Ladders 3D — Deluxe Tabletop Edition

An authentic, fully-rendered 3D tabletop Snakes & Ladders game built with Three.js and Vite for **InfinityPlay**.

## Features
- **3D Tabletop Environment**: Wooden framed board, green felt dice tray, game box, and realistic lighting with soft shadows.
- **Physical 3D Dice Simulation**: Ivory bone die with authentic pip indentation, parabolic toss trajectory, and smooth quaternion settle guaranteed to land flat on the exact rolled value.
- **Intelligent Multi-Tier AI**: Automated AI opponents with Easy, Medium, and Hard reaction delays and natural turn pacing.
- **Dynamic Camera Controls**: Tabletop, Top-Down, and Cinematic presets with mouse/touch drag orbit controls and automatic token tracking.
- **Rich Audio Synthesizer**: Web Audio API sound synthesis for dice rattles, token hops, ladder ascents, and snake slides without external media assets.
- **Glassmorphic HUD & Popups**: Real-time turn indicator, score cards, current leader crown badge, and animated dice result pop-up count banner.

## Tech Stack
- **Three.js**: 3D scene rendering, materials, procedural curves, and physics animation
- **Vanilla JavaScript & CSS**: Glassmorphic styling, responsive layout, and state machine
- **Vite**: Ultra-fast build tool and bundler
